# Security Policy

## Supported versions

Watch Tracker has not published an application release. Security support begins with the first release and the supported-version table will be added then.

## Reporting a vulnerability

Do not disclose an exploitable vulnerability in a public issue.

Use GitHub's private vulnerability-reporting feature under this repository's **Security** tab when available. If it is unavailable, open a public issue containing no exploit details and ask a maintainer to establish a private reporting channel.

Include the affected revision or release, impact, reproduction conditions, and any suggested mitigation. Maintainers will acknowledge a credible report, assess severity, coordinate remediation, and publish an advisory when appropriate.

## Scope

Security reports concern the Core Tracker and its maintained release artifacts. Vulnerabilities or harmful content in an independent Canon Pack should also be reported to that Pack's owner using its declared security or copyright contact.

## Safe harbor for good-faith research

The project welcomes good-faith research that avoids privacy violations, service disruption, data destruction, credential access, and harm to third parties. This policy does not authorize testing systems you do not own or have permission to test.
