# Contributing to Watch Tracker

Thank you for helping build Watch Tracker.

## Before opening a change

1. Search existing issues and pull requests.
2. For a substantial feature or interface change, open a proposal issue before implementation.
3. Keep each pull request focused and reviewable.
4. Add or update tests and documentation when behavior changes.
5. Do not include credentials, private data, copyrighted media, copied editorial prose, or third-party datasets without documented redistribution rights.

## Developer Certificate of Origin

Every commit must be signed off under the [Developer Certificate of Origin 1.1](DCO.md):

```bash
git commit -s -m "type: concise description"
```

The sign-off certifies that you have the right to submit the contribution under the repository license. It is not a cryptographic signature.

## Pull requests

A pull request should include:

- the problem and intended outcome;
- the scope of the change;
- validation performed and its actual result;
- user-facing or compatibility effects;
- related issues or decisions; and
- provenance and license information for any third-party material.

Maintainers may request changes, split an oversized change, or decline work that conflicts with the accepted scope or project safety.

## Canon Pack content

Franchise-specific Canon Pack content does not belong in this Core repository. Create it in an independently owned Pack repository based on the Canon Pack Template. Core compatibility is technical compatibility, not legal approval or project endorsement.

## Community standards

Participation is governed by the [Code of Conduct](CODE_OF_CONDUCT.md). Security reports and copyright concerns follow their dedicated policies.
